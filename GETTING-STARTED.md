# Math Strings: Getting Started

**https://gdrutz-blip.github.io/math-strings/**  ·  This guide is also on the site: **https://gdrutz-blip.github.io/math-strings/#/start**

A number string is a short set of related problems, shown one at a time. Each one nudges students toward a mental-math strategy. This website is your board: it shows the problems, keeps the whole string visible, and draws students' thinking cleanly so you don't have to draw it on the whiteboard.

Students see only the problems and whatever you model. Answers and teacher notes stay off the screen.

---

## Before class (5 minutes)

1. **Pick a string** from the library.
2. **Read the notes.** Click **Edit** on a string to see each problem's *Look for*, *Ask* and *Model* notes. Print that page and keep it beside you.
3. **Trim the tools.** In Present, click **⚙** in the tool bar and untick the tools you won't use.
4. **Rehearse once.** Click **▶ Present**, try a few student responses, then press **↺** (top bar) to start fresh.

## The routine in class

| Step | What you do |
|---|---|
| Show a problem | Press **→** (or click **Next**). The think timer starts. |
| Collect answers | Press **A**, type what a student says, even a wrong answer, then press Enter. Don't confirm yet. |
| Model a strategy | Pick a tool at the bottom (e.g. **Number line**), type the student's thinking, and press **Enter**. The drawing shrinks into the grid so you can add another student's way. |
| Check the answer | Click an answer to **circle** it; click again to **cross it out**. |
| Next problem | Press **→**. Earlier problems stay listed on the left. |
| Wrap up | After the last problem, click **Wrap-up** to see the whole string, ask "What did you notice?", then click **Finish**. |

## Typing models: the number line

You can type it the way you'd say it:

| Type | Draws |
|---|---|
| `38 +10 -1` | Start at 38, jump +10, back 1 |
| `38 to 48 to 47` | The same, as "jump to" |
| `76 +4 +20` | Adding up to a friendly number |
| `89 gap 100` | A bracket showing the distance (11) |
| `2x5` | Count by 2s: five jumps of 2 from 0 |

Click any label on a drawing (like **+10**) to replace it with the student's own words.

Other tools (ratio table, area model, array, integer tiles, standard algorithm and more) show a grey hint with examples when you pick them.

## Handy tips

- **Click a model** to show it full-screen. Hover to ✎ change or ✕ remove it.
- **🎲 Pick** chooses a random student. Add your class list the first time; names stay only on your computer.
- **L** hides the problem list on the left for more space.
- **⏱ Timer:** click it to start or pause. **T** does the same.
- **✏️ Pen** draws on top of anything. **Esc** stops.
- Everything you do is saved in **this browser on this computer**. Nothing is uploaded, and there are no accounts.

## Keyboard

`→` next · `←` back · `A` answer · `1` number line · `8` words · `T` timer · `R` random name · `O` whole string · `L` problem list · `P` pen · `Esc` stop/close · `?` help
